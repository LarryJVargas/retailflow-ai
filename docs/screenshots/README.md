# Capturas de Pantalla de la Aplicación

Este directorio está destinado a almacenar las capturas reales de la interfaz de **RetailFlow AI** para su presentación en GitHub.

### Nomenclatura sugerida de archivos:
1. `01_dashboard.png` - Vista general del Dashboard con los indicadores KPIs de inventario.
2. `02_catalogo_productos.png` - Tabla de catálogo de productos, búsqueda, filtros y modales.
3. `03_inventario_critico.png` - Vista dividida de productos agotados y con bajo stock con cálculo de reposición.
4. `04_analisis_gemini.png` - Panel de análisis con Gemini AI mostrando las recomendaciones y badge de procedencia.

> Las imágenes colocadas aquí con estos nombres se enlazarán automáticamente en la documentación principal.
